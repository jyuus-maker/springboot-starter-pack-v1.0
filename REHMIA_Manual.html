3. 핵심 엔티티 도메인 관계 (ERD 구조)

엔티티 (Entity) 연관 관계 (Relationship) 주요 필드 및 책임
Member 1 : N (Cart, Orders) 이메일(PK 역할), 비밀번호(BCrypt 암호화), 이름, 주소, 역할(Role)
Item 1 : N (ItemImg, CartItem, OrderItem) 상품명, 가격, 재고(stockNumber), 상품상태(SELL/SOLD_OUT), 상세설명
ItemImg N : 1 (Item) 원본 파일명, 저장 파일명(UUID), 이미지 URL, 대표이미지 여부(repimgYn)
Cart & CartItem Member(1:1), Item(N:1) 회원별 고유 장바구니 생성, 담긴 상품 수량(count) 실시간 동기화
Orders & OrderItem Member(N:1), Item(N:1) 주문 상태(ORDER/CANCEL), 주문일시, 주문수량 및 결제금액 스냅샷

Part 2. [영역 1] E-Commerce 코어 도메인 구축 내역

1. 인증 및 인가 체계 (Spring Security 6 RBAC)

  • 엔터프라이즈 롤 기반 인가: ROLE_USER(일반 고객), ROLE_ADMIN(관리자) 분리.
  • CSRF(Cross-Site Request Forgery) 방어: Form 제출뿐만 아니라 장바구니/주문 등 모든 비동기 AJAX(JSON) 요청 헤더에 X-CSRF-TOKEN 자동 주입 및 검증.
  • 인증 실패 및 인가 예외 핸들러: 비인가 사용자의 관리자 페이지(/admin/**) 접근 시 CustomAuthenticationEntryPoint가 로그인 화면으로 안전하게 리다이렉트.

2. 상품 & 미디어 파이프라인 (Multi-Slot Upload)

1 5슬롯 이미지 업로드 아키텍처

• Slot 1: 대표 썸네일 자동 지정 (repimgYn = 'Y') → 메인 갤러리 및 검색 카드 노출
• Slot 2~5: 서브/착용컷/디테일 뷰 (repimgYn = 'N') → 상품 상세 페이지 갤러리 노출

2 QueryDSL 5.1 동적 다중 조건 검색 엔진

상품 등록 기간(1일/1주/1달/6달/전체), 판매 상태(SELL/SOLD_OUT), 생성자(createdBy), 상품명(itemName)을 자유롭게 조합하여 1개의 통합 QueryDSL BooleanBuilder로 쿼리 실행.

3. 트랜잭션 기반 주문-재고 동기화 엔진

⚡ 원자적 재고 증감 비즈니스 로직 (Atomicity):
• 주문 접수: Item.removeStock(count) 호출 → 재고 부족 시 OutOfStockException 발생 및 즉시 트랜잭션 롤백.
• 주문 취소: Order.cancelOrder() 호출 → 취소 수량만큼 Item.addStock(count) 자동 수행 및 상태를 OrderStatus.CANCEL로 변경.

4. 개발자 확장 포인트 (Extension Points)

확장 기능 연동 가이드 및 추천 위치
PG 결제 연동 (토스/카카오페이) OrderController.order() 전후에 결제 검증 API 호출 및 결제키(PaymentKey) 저장 필드 추가

2. 구현된 5대 하이엔드 UX 인터랙션 메커니즘

1 Scroll-Driven Dynamic Typography (자간 가변 확장)

사용자가 스크롤을 내릴 때 헤드라인 타이틀(#heroTitle)의 letter-spacing이 -0.05em에서 0.25em으로 유연하게 벌어지며 시각적 웅장함을 전달합니다.

2 Centered Scale-on-Scroll Canvas (중심축 고정 줌인)

#scaleCanvas 컨테이너가 뷰포트 중앙에 고정된 상태에서 스크롤 진행도에 따라 스케일이 0.85에서 1.05로 확장되며 몰입감 있는 풀스크린 전환을 제공합니다.

3 Magnetic Ambient Glow (마우스 궤적 추적 조명)

마우스 커서 좌표를 requestAnimationFrame으로 추적하여 은은한 방사형 그라디언트 앰비언트 글로우(#ambientGlow)가 반응형으로 따라다닙니다.

4 Interactive Material Showcase (원단 3D 틸트 카드)

AEROKNIT™, VORTEX-FLEX™, TECH-SHIELD™ 3대 기능성 원단 카드에 마우스 호버 시 3D 회전 각도(Tilt)와 테두리 조명이 동적으로 반응합니다.

5 Real-Time Progress Gauge & 5-Step Quick Navigator

상단 1px 실시간 스크롤 진행률 게이지 바(#scrollProgress)와 우측 하단 플로팅 5단계 챕터 퀵 내비게이션으로 사용자가 원하는 섹션으로 즉시 점프할 수 있습니다.

Part 4. 개발자 실행, 시드 데이터 & 런칭 운영 가이드

1. 사전 탑재 시드 데이터 (`InitData.java`)

서버 최초 기동 시 InitData 컴포넌트에 의해 아래 기본 계정과 8종의 상품이 자동 생성됩니다.

구분 아이디 (이메일) 비밀번호 권한 기능 범위

3. 개발자 FAQ & 트러블슈팅

Q1. ./gradlew test 실행 시 실제 운영 DB와 충돌하지 않나요?

A: 충돌하지 않습니다. src/test/resources/application.properties에 독립된 H2 In-Memory DB (PostgreSQL 모드)가 설정되어 있어 실제 PostgreSQL에 영향을 주지 않고 100% 독립된 환경에서 초고속 테스트가 실행됩니다.

Q2. 업로드한 상품 이미지가 엑스박스(깨짐)로 나옵니다.

A: application.properties의 itemImgLocation (C:/shopmall/item) 및 uploadPath (file:///C:/shopmall/) 폴더가 실제로 생성되어 있는지 확인하세요.

Q3. 터미널에서 ./gradlew 실행 시 JAVA_HOME 에러가 발생합니다.

A: Windows PowerShell에서 $env:JAVA_HOME="C:\Users\<사용자>\.jdks\temurin-21.0.12.1"을 지정하거나 시스템 환경변수에 JDK 21 경로를 등록하세요.
