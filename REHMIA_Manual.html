1장. 쇼핑몰 시작하기 (서버 구동 및 접속)

쇼핑몰을 열고 고객이 웹 브라우저를 통해 방문할 수 있도록 준비하는 단계입니다.

1 프로그램(서버) 실행하기

서버가 켜져 있어야 고객들이 웹사이트를 이용할 수 있습니다.
인텔리제이(IntelliJ) 또는 터미널에서 Shop01Application.java를 실행합니다.

2 인터넷 브라우저로 쇼핑몰 접속하기

크롬(Chrome)이나 엣지(Edge) 브라우저를 켜고 주소창에 아래 주소를 입력합니다.
쇼핑몰 메인 주소: http://localhost:8080

2장. 관리자(Admin) 로그인 및 마이페이지

1. 관리자 권한으로 로그인하기

관리자 기능을 사용하려면 반드시 관리자 권한(`ROLE_ADMIN`)을 가진 계정으로 로그인해야 합니다.

  • 상단 메뉴 우측의 SIGN IN 버튼을 클릭합니다.
  • 관리자 이메일과 비밀번호를 입력하고 로그인합니다.
  • 로그인 후 상단 네비게이션에 [ADMIN CENTER] 메뉴가 자동으로 활성화됩니다.
⚠️ 비인가자 접근 차단: 일반 회원이 /admin/** 주소로 직접 진입하려고 하면 시스템에서 자동으로 접근을 차단하거나 로그인 페이지로 이동시킵니다.

3장. 상품 관리 실무 (신규 등록 / 수정 / 품절)

1. 신규 상품 등록 단계 (Step-by-Step)

1 상품 등록 페이지 진입

상단 메뉴 ADMIN CENTER → 상품 등록 (/admin/item/new)을 클릭합니다.

2 기본 정보 입력
  • 판매 상태: 판매중 (SELL) 또는 품절 (SOLD_OUT) 선택
  • 상품명: 고객에게 보여질 명확한 상품명 (예: 시그니처 테크 플렉스 레깅스)
  • 가격: 숫자만 입력 (예: 69000 → 화면에는 69,000원으로 자동 표기)
  • 재고수량: 창고에 보유 중인 실제 수량 (예: 100)
  • 상품 상세 설명: 소재, 세탁법, 착용 핏 등 에디토리얼 소개글 작성
3 이미지 파일 첨부 (중요!)

• 1번 슬롯 (첫 번째 파일): 쇼핑몰 목록 및 대표 화면에 노출되는 [메인 대표 이미지]이므로 반드시 등록해야 합니다.
• 2~5번 슬롯: 상세 설명 페이지 하단에 추가로 노출될 서브/착용컷 이미지입니다. (선택 사항)

4 저장 완료

하단의 SAVE PRODUCT (상품 등록) 버튼을 클릭하면 즉시 메인 페이지 및 상품 목록에 노출됩니다.

2. 상품 정보 수정 및 품절 처리

  • /admin/items 페이지에서 수정하려는 상품명을 클릭합니다.
  • 가격을 조정하거나, 재고를 보충하거나, 새로운 이미지 파일로 교체할 수 있습니다.
  • 갑작스러운 재고 부족 시 상태를 품절 (SOLD_OUT)로 변경하면 고객이 구매할 수 없도록 차단됩니다.

2. 재고 자동 증감 규칙 (핵심 메커니즘)

고객 행동 시스템 자동 처리 내용 관리자 주의 사항
주문 완료 주문 수량만큼 DB 재고가 즉시 자동 차감됩니다. 남은 재고가 0이 되면 자동으로 주문이 불가해집니다.
재고 초과 주문 "상품의 재고가 부족합니다" 오류 메시지가 뜨며 주문이 차단됩니다. 인기 상품은 관리자 화면에서 미리 재고를 보충하세요.
주문 취소 취소된 수량만큼 DB 재고가 원상 복구(증가)됩니다. 취소된 주문 상태는 주문취소 뱃지로 변경됩니다.

5장. 회원 및 보안 권한 관리

1. 회원 등급 체계

  • 일반 회원 (`ROLE_USER`): 회원가입을 완료한 고객. 장바구니, 주문, 마이페이지 이용 가능.
  • 관리자 (`ROLE_ADMIN`): 쇼핑몰 운영자. 일반 회원 기능 외에 /admin/** 모든 관리 기능 독점 사용 가능.

2. 보안 및 개인정보 보호

  • 비밀번호 단방향 암호화: 회원의 비밀번호는 최신 BCrypt 알고리즘으로 암호화되어 저장되므로 관리자라도 원본 비밀번호를 절대 열람할 수 없습니다.
  • CSRF 공격 방어: 모든 장바구니/주문 요청에는 실시간 보안 토큰이 적용되어 외부 악성 사이트의 위조 요청을 100% 차단합니다.

6장. 초보자를 위한 상황별 장애 조치 (FAQ)

Q1. 웹 브라우저에서 사이트가 열리지 않아요 (접속 불가).

해결 방법:
1. 백엔드 프로그램(Spring Boot)이 정상 실행 중인지 확인하세요.
2. 다른 프로그램(예: 오라클, 다른 서버 등)이 8080 포트를 사용 중인지 확인 후 충돌 프로그램을 종료합니다.

Q2. 새로 올린 상품 이미지가 화면에서 깨져요.

해결 방법:
1. application.properties 파일의 uploadPath 경로(예: C:/shop/item 또는 지정 폴더)가 컴퓨터에 실제로 존재하는지 확인하세요.
2. 권장 이미지 규격: 가로 800px 이상, 세로 1000px 비율(4:5 비율), 용량 5MB 이하의 JPG/PNG 파일 권장.

Q3. 고객이 장바구니에 담기지 않는다고 문의해요.

해결 방법:
장바구니와 바로구매는 로그인 회원 전용 기능입니다. 고객이 로그아웃 상태라면 로그인 후 다시 시도하도록 안내하세요.

7장. 일일 / 주간 운영 점검 체크리스트

  • [ ] 메인 화면 배너와 상품 리스트가 정상적으로 표시되는지 확인

매주 점검사항 (Weekly Check)

  • [ ] 서버 업로드 이미지 폴더의 저장 용량 잔여량 확인
  • [ ] 주문 내역에서 취소된 주문 목록 및 환불 상태 점검
